# Chapter 2 — Parameter Estimation

Fitting a model's parameters to data — the groundwork for building the probabilistic
models used later.

### algorithm_2_1.py — Maximum Likelihood Parameter Estimation
Finds the parameters that make the observed data most probable. `fit` builds a cost
function `f(θ)` equal to the sum of the negative log-likelihoods of the data under
the model, then hands `f` to a pluggable optimizer; minimizing the sum is the same
as maximizing the likelihood, so the optimizer returns the maximum-likelihood
parameters.

### algorithm_2_2.py — Bayesian Parameter Estimation
Instead of a single best value, returns a *distribution* over plausible parameters.
`fit` defines a probabilistic model (parameters drawn from a prior, each data point
generated by the likelihood) and draws samples from the resulting posterior with an
MCMC sampler, giving a full picture of parameter uncertainty.

## Walls / problems

- **`logpdf(dist, y)` → `dist.logpdf(y)`** (free function in Julia, method in Python).
- **Turing.jl has no drop-in Python equivalent.** The `@model` / `~` probabilistic program is rewritten by hand as a log-posterior (each `~` becomes an added `logpdf` term), and `Turing.sample(...)` becomes a pluggable `sampler(log_post, m)` you supply (a small Metropolis-Hastings, or PyMC/NumPyro). Faithful in meaning, not a literal transcription.
